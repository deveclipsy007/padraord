# Padrão RD visual assets

These assets are original visual explorations created for the Padrão RD OS prototype. The `source/` PNG files are preserved masters; `optimized/` WebP files are the Vite-imported versions used by the interface.

| Asset | Intended use |
| --- | --- |
| `context-core` | AI assistant widget and copilot panel |
| `briefing-folder` | Briefing empty state and attachments |
| `budget-ledger` | Budget context preview |
| `production-path` | Production context preview |
| `event-memory` | Operational memory panel |

The objects contain no product copy, logo, client data or external brand mark. Functional icons remain SVG-based in the React UI.
